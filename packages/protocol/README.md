# @bobs-sink/protocol

The wire protocol shared by the [bobs-sink](https://github.com/braxtonhall/bobs-sink) server and its browser
client, [`@bobs-sink/client`](https://www.npmjs.com/package/@bobs-sink/client): signed request strings, sync
messages, and the HTTP API's JSON. Sites use the client; this package is what the two have in common.
